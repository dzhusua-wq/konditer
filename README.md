# Кондитер — розпізнавання кондитерських елементів камерою

Android-додаток (офлайн): наводите камеру на квіточку, бантик, безе тощо — на екрані з'являються назва, вага та інші дані.

## Як це працює

- Камера (CameraX) кілька разів на секунду бере кадр з рамки по центру.
- Нейромережа MobileNetV3 (MediaPipe, ~4 МБ) робить з кадру числовий «відбиток» форми й текстури.
- Додатково рахується колір (середній колір + відтінки), щоб відрізняти схожі вироби різних кольорів.
- «Відбиток» порівнюється з еталонними знімками в каталозі — найближчий виріб показується на екрані.
- Модель **не треба навчати**: новий виріб додається прямо в додатку — 10–20 знімків і готово.

## Збірка APK через GitHub Actions

1. Створіть на GitHub **приватний** репозиторій, наприклад `konditer`.
2. Завантажте в нього весь вміст цієї папки (разом з папкою `.github`).
3. Вкладка **Actions** → збірка запуститься сама (~5–8 хв).
4. Готовий APK — у **Releases** (`Konditer-N.apk`). Відкрийте сторінку з телефона й встановіть.

Нові версії ставляться поверх старих, каталог зберігається (ключ підпису `app/konditer.jks` постійний).

## Як користуватися

1. **+ Додати** → назва, вага, інше (артикул, ціна, склад) → **Далі: знімки**.
2. Виріб у рамці → **Знімок**. Зробіть 10–20 знімків: різні боки, нахили, відстань. Об'ємні — покрутіть.
3. **Готово**. Тепер просто наводьте камеру — виріб упізнається.
4. **Каталог → + З фото**: новий виріб з картинок у галереї (наприклад, файл малюнка для топера чи печива). Найкраще потім ще дозняти 3–5 разів камерою.
5. **Каталог** → натисніть на виріб: дозняти камерою, додати фото з галереї, редагувати, видалити.
6. **Каталог → Файл**: зберегти каталог у файл (резервна копія або перенесення на інший телефон) і завантажити назад.

## Поради для точності

- Однаковий фон (білий аркуш) і однакове світло — найбільший приріст точності.
- Знімайте еталони в тих самих умовах, де потім розпізнаватимете.
- Якщо два вироби плутаються — дозніміть обидва з різних ракурсів.
- Мала й велика однакова квітка камерою відрізняються погано: тримайте телефон на однаковій відстані (штатив/підставка).
- Рамка жовта = кілька виробів дуже схожі, зелена = впевнений збіг.

## Налаштування в коді

- `MainActivity.THRESHOLD` (0.75) — поріг «Не впізнано».
- `Recognizer.SHAPE_WEIGHT / COLOR_WEIGHT` (0.65 / 0.35) — що важливіше: форма чи колір.
- `FrameOverlayView.FRACTION` (0.75) — розмір рамки.
