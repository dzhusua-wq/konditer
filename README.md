# Кондитер — розпізнавання кондитерських виробів камерою

Android-додаток, працює офлайн. Наводите камеру на квіточку, бантик, цукерку, топер чи печиво з малюнком — на екрані назва, вага, ціна, артикул, опис і фото виробу.

## Як працює розпізнавання

1. Камера кілька разів на секунду бере кадр з рамки.
2. Виріб автоматично відокремлюється від фону (стіл, тіні) — власний алгоритм за кольором країв рамки.
3. Нейромережа робить «відбиток» форми й текстури, окремо рахується колір:
   - **Точна — DINOv2-small** (Meta, ONNX Runtime) — за замовчуванням;
   - **Швидка — MobileNetV3-large** (MediaPipe) — для слабких телефонів.
4. Відбиток порівнюється з еталонами каталогу. Кожен еталон зберігається у 4 поворотах — виріб упізнається під будь-яким кутом.
5. **Впевненість самокалібрується:** порівнюється з тим, наскільки еталони цього виробу схожі між собою, і з відривом від другого кандидата та порожнього фону.
6. **Плоскі вироби** (топери, печиво з малюнком) додатково перевіряються за сотнями дрібних точок малюнка (OpenCV ORB + RANSAC) — так розрізняються навіть картинки, що відрізняються лише написом.
7. Результат фіксується, коли виріб переміг у 4 з 6 останніх кадрів — назва не «миготить».

Модель не треба навчати: вироби додаються прямо в додатку.

## Основні можливості

- **Додавання виробу:** «+ Додати» → дані → автозйомка (повільно рухайте телефон навколо виробу) або кнопка «Знімок».
- **З готових картинок:** Каталог → «+ З фото» (файли друку топерів і печива).
- **Навчання на ходу:** «Вірно ✓» запам'ятовує ракурс, «Не те» — вибираєте правильний виріб, і додаток вчиться.
- **Фон:** Налаштування → «Навчити фон» — 5 знімків порожньої поверхні, тоді порожня рамка не «впізнається».
- **Перевірка якості:** після додавання — попередження про схожі вироби; Налаштування → «Перевірити каталог» — точність і пари, що плутаються.
- **Еталони:** Каталог → виріб → «Переглянути еталони» — видалення невдалих фото.
- **Камера:** зум 1×/2×/3× для дрібних елементів, фокус дотиком, «Світло», підказки «Темно» / «Розмито».
- **Дані:** резервна копія каталогу в .zip і відновлення (перенесення на інший телефон). При зміні нейромережі вектори перераховуються з фото автоматично.
- **Журнал помилок:** Налаштування → «Надіслати».
- **Налаштування нейромережі:** модель (точна/швидка), виділення виробу від фону, перевірка деталей. Вектори кожної моделі зберігаються окремо; при зміні перераховуються з фото автоматично.

## Збірка

Кожен push у `main` запускає GitHub Actions: юніт-тести → APK → Releases (`Konditer-N.apk`). Нові версії ставляться поверх старих без втрати каталогу.

## Поради для точності

- Однакова підкладка й світло — найбільший приріст точності. Навчіть фон.
- Знімайте еталони в тих самих умовах, де потім розпізнаватимете.
- Глянцеві вироби — світло збоку, без відблисків.
- Розмір камера бачить погано: для малої/великої версії одного виробу тримайте однакову відстань.
- Технічні дані (оцінки, різкість) — Налаштування → «Технічні дані на екрані».
